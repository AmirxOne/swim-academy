# 🏊 سیستم مدیریت آموزشگاه شنا

<div dir="rtl">

وب‌اپلیکیشن مدیریت آموزشگاه شنا — ساخته شده با Next.js،专为 مربیان استخر طراحی شده.

## ✨ امکانات

| بخش | توضیحات |
|------|---------|
| 🏠 داشبورد | برنامه روزانه، آمار سریع، ثبت حضور سریع |
| 👥 شاگردان | مدیریت کامل، جستجو، تاریخچه جلسات و پرداخت‌ها |
| ✅ حضور و غیاب | حاضر / غایب / **غیبت موجه** (کسر نمی‌شود) |
| 📅 تقویم | نمای هفتگی، رزرو ساعت، ساعات خالی |
| 💰 مالی | حسابداری، سهم مربی، تفکیک بر اساس نوع کلاس |
| 📊 خروجی اکسل | شاگردان، حضور و غیاب، مالی |
| 🔗 لینک شاگرد | صفحه اختصاصی فقط خواندنی برای هر شاگرد |
| 🔄 تمدید | هشدار خودکار + متن پیام آماده |
| 📝 کلاس جبرانی | ثبت جلسه جایگزین برای غیبت موجه |

## 🔧 تکنولوژی

- **Next.js 16** + React 19 + TypeScript
- **Prisma 6** + SQLite
- **Tailwind CSS 4**
- **PWA** — نصب روی گوشی
- **RTL فارسی** + تقویم جلالی

## 🚀 اجرا

```bash
npm install
npx prisma db push
npm run seed
npm run dev
```
